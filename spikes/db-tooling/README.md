# ADR-0014 database tooling spike (throwaway)

Validation code for [ADR-0014](../../docs/DECISIONS/0014-database-tooling.md). Not application code and not the M1 schema. Results: [`docs/SPIKE_DB_TOOLING_REPORT.md`](../../docs/SPIKE_DB_TOOLING_REPORT.md).

## Requirements

- Node.js 26.13.0 (`.nvmrc`) and pnpm 12.16.1 (`packageManager`)
- A Docker engine (validated with Colima 0.10.3, Docker Engine 29.5.2)
- Port `127.0.0.1:54329` free

## Run

```sh
cd spikes/db-tooling
nvm use
pnpm install --frozen-lockfile
pnpm spike                      # everything, from a fresh database
SKIP_INSTALL_CHECK=1 pnpm spike # skip the arm64/amd64 container install builds
```

Individual steps: `pnpm db:reset`, `pnpm typecheck`, `pnpm db:types:check`, `pnpm test`, `bash scripts/install-check.sh`.

Clean up: `docker compose down --volumes`.

## Layout

| Path | Purpose |
| --- | --- |
| `docker-compose.yml` | Disposable `postgres:18.6` pinned by digest, tmpfs data, localhost only |
| `bootstrap/bootstrap.sql` | Superuser step: `schoolos_owner` (CREATEROLE, no SUPERUSER/BYPASSRLS), databases |
| `db/migrations/` | dbmate migrations run as `schoolos_owner` |
| `src/db.ts` | `withTenant` / `withoutTenantContext` over one `pg.Pool` and one Kysely |
| `src/db-types.ts` | Generated by `kysely-codegen`; checked by `pnpm db:types:check` |
| `tests/` | Validation matrix V1–V12 |
| `tests/fixtures/txprobe/` | dbmate transaction-behaviour probes (scratch database) |
| `Dockerfile.install-check` | Clean install from the lockfile on linux/arm64 and linux/amd64 |

All data is synthetic. Passwords in this directory are local-only placeholders for the disposable container.
